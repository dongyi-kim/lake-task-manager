## 자동 checker와 사람 판정 불일치

- STARR1 자동 결함 3건은 모두 false positive다. DOM leaf/활용형/공동 목적어를 좁은 lexical
  window로 검사해 실제 존재하는 완료·미확정·rollout gate를 놓쳤다.
- S8과 CTX3 자동 green은 false pass다. source class가 존재한다는 사실이 최신 entity coverage를
  보장하지 않았고, context checker가 intermediate turn의 exact fields를 검사하지 않았다.
- S6의 “결과 표 또는 0건 없음” 경고는 진척 narrative에 맞지 않는 false positive다.
- MTG7 자동 RED는 pending 부재라는 점에서는 true fail이지만, row identity를 title substring으로
  찾는 checker도 writer/reader가 함께 등장하는 제목에서 별도 오탐을 만든다.
