# 데이터 자산·업무 이력 조사

테이블·Job·기술·현재 작업의 값은 권한 있는 최신 업무 근거에서 조회한다.
정책의 예시 이름이나 기술 일반론을 실제 운영 사실로 승격하지 않는다.

## 자료 연결

최초 요청·개발 티켓, 후속 변경, 장애 댓글, field changelog, Confluence 본문을 연결한다.
검색 발췌만으로 문서 전체를 읽었다고 하지 않는다. 변경 시각·대상·권위·조회 시점을 함께 판단한다.
가장 최근 글이라는 이유만으로 낮은 신뢰 주장을 확정하지 않고 출처 충돌을 밝힌다.
table/column/API/Job/ticket key/URL은 원형을 유지하며 schema 포함·제외 이름을 필요에 따라 따로 검색한다.
공개 mock의 fdc.fdc_trace_summary_ic와 etl_fdc_trace_summary_ic_30m는 합성 예시다.
이름 접미만으로 주기·성공 여부·현재 운영값을 추론하지 않는다.

## 답변과 외부 조사

확인된 사건을 출처와 시간 순서로 설명하고 과거·현재 확인값·추론·open fact를 구분한다.
누락 page·stale·partial·조회 실패가 있으면 전체 이력을 확인했다고 하지 않는다.
무관한 자산의 성능·원인·담당을 가져오지 않는다. 확인한 범위와 필요한 후속 확인을 적는다.
외부 기술 조사는 일반화한 기술어·공식 문서를 사용하고 내부 식별자·사용자 ID·비공개 본문을 검색어로 보내지 않는다.
외부 자료는 일반 동작의 근거이며 내부 적용 여부는 내부 근거로 확인한다.
한 source의 여러 발견은 한 번호 아래 하위 발견으로 묶고 marker를 실제 link로 연결한다.
