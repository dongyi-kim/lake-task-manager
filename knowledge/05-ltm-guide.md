# LTM(Lake Task Manager) 사용 가이드

사용자가 "LTM 에서 ~~ 어떻게 해?"라고 물을 때 에이전트가 근거로 대는 사용법 문서.
여기 없는 기능을 지어내지 말 것 — 실제 화면 기준으로 유지한다.

## 화면 구성

- **LTM Agent (메인, #/home)**: AI 어시스턴트 대화 화면. 좌측 사이드바(새 대화·최근 대화·
  모델 설정), 중앙 대화, 우측에 티켓 생성 시 초안 미리보기 패널이 열린다.
- **WBS Dashboard**: WBS Task 별 진척률 롤업. 막대를 누르면 해당 Epic/Task 로 들어간다.
- **현안 (PMO_VIT)**: PMO_VIT 라벨이 붙은 경영진 보고 현안 트리만 모아 본다.
- **인력 워크로드**: 사람별 진행중/열림/최근 완료 건수. 이름을 누르면 그 사람 티켓 목록.
- **Task**: 티켓 목록·검색. 상단 검색(단축키 `/`)은 Jira+Confluence 통합 검색이다.

## 티켓 다루기

- 티켓 키(DL-123)를 어디서든 클릭하면 **티켓 다이얼로그**가 뜬다: 본문·코멘트·계보
  (상위/형제/하위)·타임라인·첨부·관련 문서를 한 화면에서 본다.
- 필드 수정: 다이얼로그에서 값(담당자·우선순위·마감 등)을 직접 클릭하면 인라인 편집
  팝업이 뜬다. 편집 가능 여부는 Jira 권한(editmeta)을 따른다.
- 코멘트: 다이얼로그 하단 에디터. `@` 로 사람 멘션, `/` 로 표·코드·티켓/문서 링크 삽입.
- 새 티켓: Task 화면의 [＋] 또는 티켓 다이얼로그의 '하위 티켓 만들기'. 여러 건은
  Bulk 생성 다이얼로그(검증 후 일괄 생성).

## AI 에이전트(이 어시스턴트) 사용법

- 입력창에서 `@` 멘션, `/` 로 티켓·문서 링크를 넣을 수 있다. Ctrl+Enter 전송.
- 할 수 있는 일: 업무 착수(과거 조사→초안→담당 추천→승인 생성), Epic 생성, Bug 신고,
  기존 티켓 수정·댓글, 진척률·정체·미배정 조회, 사람/모듈 활동 정리, 지식 질문,
  조건 검색(자연어→JQL).
- **승인 전에는 아무것도 만들거나 바꾸지 않는다** — 생성/변경은 항상 승인 카드에서
  [이대로 생성/변경]을 눌러야 실행된다. 담당자는 카드의 후보 중 고르거나 직접 지정한다.
- 모델·API 키·내 프롬프트는 사이드바 상단 ⚙ 설정에서. '간단한 역할 모델'을 지정하면
  의도 분류 등 가벼운 단계는 저렴한 모델로 돈다.
- 대화 우상단 [📋 대화 복사]로 대화 전체를 마크다운으로 복사할 수 있다.

## 자주 묻는 것

- **진척률이 대시보드와 다르게 보이면**: 분모 규칙(Epic 미연결·VoC 제외)을 먼저 확인 —
  산식은 `02-progress-formula.md` 기준으로 대시보드와 동일하다.
- **티켓이 대시보드에 안 보이면**: Epic Link 가 비어 있는지 확인(미연결은 집계 제외).
- **강제 새로고침**: 좌하단 ↻ 버튼 — 서버 캐시를 건너뛰고 다시 읽는다.
