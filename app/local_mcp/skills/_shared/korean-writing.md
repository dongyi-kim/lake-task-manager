# 한국어 표현과 사실 검수

작업·점검은 짧은 개조식과 checkbox, 여러 항목의 비교는 표, 결과·원인·질문은 조사와 연결어가 살아 있는 문장으로 쓴다. 사용자 양식과 기존 문서의 요청하지 않은 부분을 보존한다.

| 피할 표현 | 근거에 맞는 표현 |
|---|---|
| 적재 검증 완료 대응 진행 | 적재 건수를 검증했고, 오류 2건은 수정 중입니다. |
| A 개발 완료 | A는 현재 담당자입니다. 실제 개발 완료 여부는 확인하지 못했습니다. |
| 전체 0건 | 권한 오류로 조회하지 못해 전체 건수는 미확인입니다. |
| 테이블 3개 처리 완료 | 고유 테이블 2개에 대해 개선 작업 3회를 완료했습니다. |
| 취소 예정으로 제외 완료 | 취소 계획만 확인됐습니다. 실제 실행·취소 여부는 추가 확인이 필요합니다. |

긴 명사 연결·번역투·불필요한 영어 병기를 줄인다. code, SQL/JQL, 필드·도구·인자·key·ID·URL은 그대로 보존한다. 문장을 줄일 때 수치·기한·부정·보류·담당자·조건·인과관계를 바꾸지 않는다.

제출 전 진행/완료/계획/취소/미확인의 구분, 합계와 단위, 실제 출처 링크, 원문 주장과 자기 판단의 구분을 확인한다. 이미 승인된 내용은 다시 묻지 않는다. 초안 요청만으로 게시하지 않는다. 표·멘션·링크·체크 상태·코드·이미지의 형식은 해당 작성 스킬을 따른다.
