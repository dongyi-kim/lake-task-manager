# 범위·인물·기준 시점

조사 시작 시 질문, 프로젝트/space, 인물·모듈·Epic/WBS/Task, 기간, 시간대, 기준 시각과 집계 단위를 명시한다. 사용자 시간대를 알 수 없으면 연결된 context로 확인하고 결과를 바꿀 때만 질문한다.

- 오늘·어제·지난주·지난달은 실행 날짜에 해석한다. 지난 달력 주와 최근 7일을 구분하고 `[시작, 종료)`를 사용한다.
- 현재 자료로 과거 기간 실적을 설명하는 것과 당시 상태를 재현하는 것은 다르다. 현재 Done/담당자/updated를 과거 사실로 소급하지 않는다. 과거 revision·전이 근거가 없으면 재현 불가능 범위를 적는다.
- 사람은 `search_users`와 티켓 context의 실제 ID로 식별한다. 성 제외·호칭·회사명은 검색 단서이며 ID가 아니다. 동명이인은 후보의 소속·티켓 문맥으로 해소하고, 남은 모호성이 결과를 바꾸면 후보를 제시해 확인한다.
- 현재 assignee, reporter, 댓글 작성자, 변경자, 실제 개발 기여는 서로 다른 역할이다. 댓글만 썼다는 이유로 수행 실적을 부여하지 않는다.
- Jira Component와 인력 소속 모듈, 현재 WBS 매핑과 과거 WBS 매핑을 구분한다. 질문의 기준을 임의로 바꾸지 않는다.
- 테이블은 가능하면 시스템/환경/DB/schema/table로 식별한다. rename·alias는 연결 근거가 있을 때만 합친다. DB의 실제 대소문자 규칙을 무시해 모두 lowercase로 만들지 않는다.

범위가 바뀌면 새 조사 ID 또는 새 세대를 만들고 변경 이유를 기록한다. 이전 기간의 완료 표시를 새 기간에 그대로 가져오지 않는다.
