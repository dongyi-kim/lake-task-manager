# 요청별 조사 완료 조건

| 요청 | 필요한 결과와 경계 |
|---|---|
| R01 기능·키워드 경위 | 티켓·댓글·문서의 업무 사건과 날짜; field changelog 나열로 대체하지 않음 |
| R02 기간 신규 적재 수 | 실제 실행·완료, 표준 식별자, 중복·취소·기간 밖·기존 개선 제외 |
| R03 오늘 모듈 활동 | 진행·장애·결정·댓글·완료; 활동 없는 현재 상태와 구분 |
| R04 Epic/WBS 진척 | 하위 Task/SubTask, 부모 상태 별도, 동일 산출물 중복 방지 |
| R05 개인 수행 업무 | 실제 ID·기간·기여; 현재 할당과 구분 |
| R06 여러 사람 실적 | 개인 근거와 공동 작업, 전체 합계에서 중복 제거 |
| R07 운영실적 | 신규/개선/중단별 티켓·VoC·고유 테이블·작업 사건 수 |
| R08 참여자·기여 | 담당·보고·댓글·변경·문서 역할 구분; 댓글을 개발 기여로 단정하지 않음 |
| R09 테이블 경위 | 환경·DB·schema·동명·rename/alias의 검증된 연결 |
| R10 이전 보고 비교 | 기준 revision/as-of와 신규·변경·미완료·제외 구분; 양식 유지 |
| R11 사용자 양식 보고 | 원래 양식, 확인 사실만 작성, 미확인/실패/해당 없음 구분 |

모든 요청에서 조회 범위·자료 나이·근거·미확인 이유를 검수한다. 필요한 출처가 실패했거나 collection이 불완전하면 확인된 결과까지만 답한다. 대규모 조사나 중단 요청은 다음 작업과 로컬 복구 위치를 남긴다.
