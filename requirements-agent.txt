# Lake PMO Agent — **이제 requirements.txt 에 합쳐졌다.**
#
# 왜 합쳤나: 런처(배포 repo 의 run-core.ps1)는 `requirements-sso.txt` → `requirements.txt`
# 만 설치한다. 에이전트 의존을 따로 두면 유저는 앱을 켤 때마다 "AI 에이전트가 켜져 있지
# 않습니다 — pip install -r requirements-agent.txt" 화면을 본다. 유저의 배포 repo 는 대개
# 최신이 아니라 **런처를 고쳐도 그 유저에게는 안 간다**. 안내를 읽고 손으로 pip 를 치는
# 유저는 없다 — 선택 설치가 아니라 그냥 안 되는 기능이 된다.
#
# 이 파일은 **옛 안내·스크립트가 깨지지 않도록** 남겨 둔 얇은 껍데기다.
#   pip install -r requirements.txt            ← 이것만으로 에이전트까지 다 깔린다
#   pip install -r requirements-agent.txt      ← 같은 결과(아래 include)
