Replace example values/IDs; no default decision. Schema order: contract, status, payload, each once. ok requires mode=task|subtask|epic, questions, items. Questions belong ONLY in payload.questions: for clarification use status="ok", items=[] and concrete question objects; for a draft use questions=[] and items. Never combine questions with draft items. blocked: payload={}. No other root fields.
Each question object has plain kind=text|choice|multi|date, optional field, plain input_need=required|optional, wrapped question and why_required, and optional wrapped options. The question's kind is not the nested narrative kind=inference|recommendation. Preserve the reason and available choices; do not emit an additional copy of the question outside payload.
Payload keys: mode, questions, items, interpretation, structure, structure_why, rationale. Item metadata never belongs at payload root. Never put rationale inside items. summary/background/scope_in/dod are wrapped; type/issue_type plain. Include requested children. assignee/parent_ref are unsupported.
Authored text: {value,kind,source_ids}, kind=inference|recommendation only. Proposed work is recommendation; user-reported context and synthesized relevance are inference, not verified facts. Facts use a DIFFERENT shape: {kind:"fact",source_id:"ACTUAL_ID",source_path:"/tickets/0"}. Select a complete record from that source's fact_paths.paths, relative to decoded content, not /content.
