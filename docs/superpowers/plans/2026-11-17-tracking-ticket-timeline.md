# Tracking 상세 타임라인 구현 계획

사용자 요청: Task·Sub-task 상세 상단에서 상태 변화와 댓글 작성 시점을 가로 시간축으로 확인.
기존 승인된 디자인·기능 유지. 선택 기간의 자체 티켓 사건만 사용하며 추가 수집 없음.

## 설계

- 날짜 간격을 유지하는 수평 시간축. 상태와 댓글을 구분한 날짜별 사건 표시.
- 동일 날짜의 여러 전환·댓글을 순서대로 표시. 긴 축은 패널 내부에서 가로 스크롤.
- 변화가 없는 경우와 미수집을 구분. 현재 상태를 기간 시작 상태로 사용하지 않음.
- 사건 클릭·키보드 선택은 기존 근거 선택 동작을 사용. 하위 티켓 사건 제외.
- 기존 참조 시안의 청색·회색·완료 녹색, 글꼴·테두리·포커스 스타일 재사용.

## 구현 순서

1. 순수 데이터 모델: 자체 사건 필터·KST 날짜·안정적 정렬·중복 제거·구간 경계.
2. 독립 Vue 타임라인 컴포넌트와 전용 CSS. 상세의 첫 영역에 통합.
3. 의미 검증: 0/1/여러 상태 전환, 재오픈, 댓글만 존재, 동일 시각·부분 수집·하위 제외.
4. 실제 Vue 브라우저: Task/Subtask 표시, 사건 이동, 좁은 패널·종단 화면, 추가 API 0, 가로 넘침 격리.
5. 1280/1440 밝은·어두운 화면 직접 확인 후 관련 회귀 검증.
