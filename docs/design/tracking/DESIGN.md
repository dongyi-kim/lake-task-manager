# Tracking — 업무 진척 읽기 화면

## 의도

일간·주간 보고와 진척 모니터링에 사용하는 데스크톱 업무 도구.
왼쪽에서 업무 범위를 선택하고 오른쪽에서 요약·상세를 전환. 기능 배치와 집계 의미 보존.

## 정보 구조

- 상단: 기간·대상·조회 상태
- 왼쪽: WBS 화면을 따른 한 줄 트리, 모듈 / WBS / 이슈 유형 배지, 작은 사각 `+ / −` 폴딩, 너비 조절
- WBS 직속 업무는 `소속 Epic 없음` 그룹으로 묶고 중립색 점선 `미소속` 배지 표시. 실제 Epic과 기존 VOC 분류의 의미 보존
- 오른쪽: 현재 선택 경로 → 요약 / 상세 탭 → 검색·강조 → 내용
- 요약: 성과 하이라이트·그룹별 업무·날짜별 활동·계층별 집계
- 그룹핑: 계층 → 현재 상태(기본), 현재 상태 → 계층. 현재 Jira 상태와 기간 활동 분류는 독립. 선택 저장
- 각 그룹과 하위 그룹 접기, 필터·고정·공유 티켓 중복 제거 유지
- 날짜별 활동 그룹핑: 그룹핑 안함(전체 최신순) / 티켓별로 보기(기간 전체) / 날짜 내 티켓 묶기(한국 날짜 → 티켓). 선택 저장
- 날짜·티켓 묶음은 최신 활동 순. 제목·티켓 번호, 활동별 시각 유지. 그룹핑 전 검색·강조·계층 범위 적용
- 시간 기록·추정치·worklog ID 변경과 Resolved → Closed는 표시·집계·AI 근거에서 제외. 저장된 원본과 진짜 완료·재개 이력 보존
- 티켓 제목 바로 아래 작은 파란 계보. 자신의 제목 제외, 복수 경로는 툴팁에 모두 표시
- 상세: 선택 항목의 이름·현재 상태 → 기간 변화 → 날짜별 이력·댓글
- 종단 Task/Subtask: 상세 기본 선택, 요약 비활성화. 빈 WBS/Epic은 집계 범위로 유지
- 트리의 숨은 근거 버튼과 화면을 가리는 별도 상세 패널 제거

## Typography

기존 Pretendard 사용. 제목 20–23px, 섹션 14px/650, 댓글 본문 13px/1.6,
트리 제목은 모듈 12.5px/700, WBS 12px/650, Epic 11.5px/600, 업무 11px/500, 서브 10.5px/400. 날짜·작성자 12px, 트리 유형 배지 9px.
트리 이름은 nowrap + ellipsis + 전체 제목 tooltip. 이력 본문은 자연스러운 한국어 줄바꿈.
변동 수치 tabular-nums. 댓글은 3줄 이상이면 2줄 미리보기와 펼치기/접기.

## Color / Surface

`app/static/styles/tokens.css`의 테마 토큰을 그대로 사용. 별도 팔레트 추가 없음.

- 배경 `--bg`, 콘텐츠 `--panel`, 도구·날짜 구분 `--panel-2`
- 경계 `--border`, 강조 경계 `--border-hi`, 본문 `--text`, 메타 `--muted`
- 활성 선택 `--accent`, 완료 `--good`, 주의 `--warn`
- 유형: 기존 `lib/colors.js`의 유형 라벨·`TYPE_BG` 재사용. Epic `--ty-epic`, Task `--ty-task`, Sub-Task `--ty-sub`, Bug `--ty-bug`; Story·개선·기능도 WBS와 같은 토큰. 모듈·WBS·미소속은 중립색
- 색상은 문자 배지·선택선과 함께 사용. 완료·경고 외의 넓은 채색 면적 지양
- 밝은/어두운 테마 모두 검증. 표면·테두리로 정보 영역 구분, 장식 그림자 최소화

## Spacing / Radius

기본 간격 4/8/12/16/24px. 기존 앱 밀도를 유지하는 3/4px 모서리.
트리 행은 모듈·WBS 34px, Epic 28px, 업무·서브 26px. 폴딩 시각 요소 13px, 클릭 영역 24px. 상세 이력 간격 16px. 트리 들여쓰기 단계당 16px.
WBS의 `--grid2` 계보 선과 마지막 자식의 ㄴ자 연결, 옅은 행 구분선을 적용. 종단에는 불필요한 점 장식 없이 폴딩 위치만 확보.
본문과 트리는 동일한 시작선. 댓글은 읽기 폭을 유지하되 표·코드는 내부 가로 스크롤.

## Interaction / Motion

- 탭: 활성 밑줄 + 표면 차이 + aria-selected. 좌우/Home/End 키. 종단 요약 disabled와 이유 표시
- 트리: 선택 행 표면·좌측 표시선, hover와 focus 구분, 전환 시 접기/검색 보존
- 너비 조절: 보이는 경계/손잡이, 드래그·키보드·폭 선택 대안, 사용자 폭 저장, 본문 최소 폭 확보
- 댓글: 정화된 HTML, 출처 키·작성자·시각 표시, 펼치기 상태 aria-expanded
- 짧은 색상·opacity 상태 변화만 150ms. 크기 변화 애니메이션 없음. reduced-motion 적용
- 모든 제어에 focus-visible 2px. 데이터 없는 경우 미확인/없음과 수집 상태 구분

## 적용 스킬 / 검증

- ui-ux-pro-max: dragging movements / keyboard 검색 결과 적용. disclosure 검색은 관련 결과 없어 미적용
- omd-feel: 표면 구분, 상태 피드백, 간격, 포커스, reduced-motion
- omd-designer-review: 이 문서를 기준으로 실제 데스크톱 화면·코드 대조
- frontend-testing-debugging: 로컬 저장 실행으로 조상·종단 탭/너비/긴 댓글/표/목록/다크 모드 확인
- 새로운 Jira 조회 없이 탐색. HTML 렌더링은 기존 정화 경로 재사용
