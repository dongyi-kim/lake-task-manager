# Tracking 시간축 시안

상태: 승인된 시안의 실제 Tracking 적용 완료. 검증 결과: `docs/validation/2026-11-17-tracking-time-axis.md`.
시안: `/design/tracking-time-axis.html` — Task / Epic, 전체 기간 / 시간 확대 전환.

## 요청과 방향

날짜별 긴 텍스트 열을 없애고 실제 시각에 놓인 점·선·아이콘·짧은 말풍선으로 변화 표현.
기존 Tracking의 청색·녹색·회색 역할, 좌측 계층, 상단 조회 조건 유지. 데스크톱 대상.

- 기본: 단일 통합 시간축. 자체 사건과 직속 하위 작업의 주요 변화를 한 선에 함께 표시.
- 개별 업무 행: `하위 작업별 펼치기`를 선택할 때만 표시. Task·Epic 모두 기본 접힘.
- 변화 주체는 말풍선의 업무명, 표식의 자체/하위 표현, 원본 근거의 업무명·키로 식별.
- 날짜별 열: 빈 날짜와 장문이 영역을 차지하는 기존 문제를 반복하므로 제외.

## 화면

- 상단: 티켓 이름·현재 상태·현재 조회된 하위 Done/전체. 활동 수를 진척률로 사용하지 않음.
- 작은 전체 기간 띠: 시간대별 활동 밀도와 현재 확대 날짜. 밀도는 진척이 아니라 탐색 단서.
- 전체 기간: 실제 경과 시간의 간격 유지. 날짜 선택 시 해당 날짜의 시간 눈금 확대.
- 시간 확대: 09–18시 / 24시간 전환. 좁은 범위 밖 사건 수를 버튼에 표시하고 24시간으로 바로 확인. 야간 23:10 댓글 예시 포함.
- Task: 자체 사건과 Sub-task 주요 변화를 한 축으로 요약. Epic: 자체 사건과 하위 Task 주요 변화를 한 축으로 요약.
- 통합 축은 중립색의 시간 흐름. 서로 다른 업무의 상태를 하나의 상태선으로 합성하지 않음.
- 채운 상태 표식은 자체 사건, 테두리 상태 표식은 하위 사건. 말풍선에 해당 업무명을 표시.
- 확장 시 하위 작업별 상태선을 추가. 현재 상태는 행 왼쪽, 역사적 상태는 선에 표시. 과거 근거가 없으면 점선. 빈 기록을 미진척으로 해석하지 않음.
- 확장·접기 전후 통합 축, 완료 수, 사건 수, 선택 시간 범위 동일. 같은 사건의 중복 렌더링을 새 사건으로 집계하지 않음.

## 사건과 밀집 처리

- 진행: 청색 선·재생 표식. 완료: 녹색 선·체크. 재오픈: 황색 선·되돌림. 색과 모양 함께 사용.
- 댓글: 말풍선 아이콘. 가까운 댓글만 숫자 묶음으로 표시하며 클릭하면 시작/끝 시각과 개별 항목 확인. 근거 펼치기는 묶음 전체의 본문을 시각·제목별로 구분.
- 상태 전환은 묶지 않음. 좁은 구간에서 점의 x좌표를 유지한 채 세로로 분리하고 연결선 표시.
- 상태 아이콘 16px, 댓글 아이콘 18px. 시각 크기보다 넓은 클릭 영역과 키보드 포커스 유지.
- 안내 말풍선은 높이 24px의 `업무명 · 변화` 한 줄. 날짜·시간은 안내에 표시하지 않으며 클릭한 상세 근거에서 확인.
- 말풍선 너비를 측정해 위아래 줄에 겹치지 않게 배치. 밀집 시 말풍선을 옮기고 실제 아이콘의 x/y에서 연결선을 그림. 사건의 시간 좌표는 이동하지 않음.
- 아이콘·연결선·말풍선은 호버/포커스 시 함께 강조. 제목이 잘리거나 같은 업무명이 반복되면 티켓 키로 보완.
- 같은 시간대 사건이 많아도 표식의 세로 위치를 반복 사용하지 않음. 화면 크기·기간·확대 범위 변경 시 위치와 연결선 재계산.
- 클릭·키보드로 말풍선 열기. 정확한 시각, 업무명·키, 짧은 설명, 근거 펼치기. Esc 닫기·원래 표식으로 포커스 복귀.
- 댓글 원문·긴 증빙은 시간축 밖의 근거 영역에서 확인. 자체/하위 사건과 현재 선택 범위 계약 유지.
- 일괄 펼치기 시 긴 본문을 시간축에 쌓지 않음. 요약 행과 세부 근거의 역할 분리.

## 구현 시 보존할 계약

- 저장된 사건·시각·상태 이력만 사용. UI 확대·선택을 위한 Jira/MCP 추가 조회 없음.
- 상태 구간을 그리려면 해당 구간의 이력 완전성이 필요. 현재 상태로 과거 선을 역추정하지 않음.
- 관측 시각 이후는 상태 확정 구간으로 그리지 않음. 시각 미확인 기록은 별도 영역에 수량과 근거 표시.
- 댓글 74건·상태 다중 변경·부분 수집·동시 사건·재오픈·변화 없음·많은 하위 작업을 별도 검증.
- 전체 기간과 확대 범위를 항상 명시. 비선형 압축·야간 생략을 숨겨 실제 경과 시간이 왜곡되지 않도록 함.
- 시안의 사건 설명은 예시 문구. 제품 적용 시 임의 진척 추론이나 자동 AI 호출을 추가하지 않음.

## 확인

1540px Task/Epic 및 1280px 어두운 테마에서 화면 확인. 페이지 가로 넘침·브라우저 오류 없음.
날짜/배율 전환, 23:10 야간 사건 접근, 댓글 4개 묶음과 본문 4개, Esc·포커스 복귀, 근거 펼치기, 댓글 표시 토글 확인.
이동·상호작용 중 API 요청 0건. JS 문법 검사·diff 공백 검사 통과.
단일 축 기본값과 Task 하위 5행 / Epic 하위 6행 확장 검증. 접기 전후 완료 수·사건 수·시간 범위 동일.
하위 완료 사건의 근거가 해당 티켓 `DL-10002`로 연결됨을 확인. 댓글은 같은 출처끼리만 묶음.
작은 아이콘·한 줄 안내 후 1540/1280px에서 일반 6개·밀집 12개 말풍선의 겹침 없음 확인.
말풍선 높이 24px, 연결선 시작점과 실제 아이콘 좌표 일치, 크기 변경 시 재배치 검증.
일반 통합 축 높이 258px → 158px. 밀집 12개는 화면 폭에 따라 268/290px로 확장.
독립 HTML/CSS/JS는 디자인 비교용 예시 데이터 산출물로 유지.

## 실제 데이터 적용 시 차이

- 단일 사건·안내 클릭은 기존 상세 근거의 원본 사건으로 바로 이동. 정확한 시각·업무명·키·본문은 해당 근거에서 확인. 같은 출처 댓글 묶음만 로컬 목록을 열고 개별 근거를 선택.
- 하위 작업별 축은 실제 사건 표식과 중립 점선으로 표시. 시안의 연속 상태 색 선은 적용하지 않음. 저장 사건은 기간·사람 조건으로 필터링되어 있어 `historyComplete`가 참이어도 화면의 인접 사건 사이에 다른 담당자의 상태 전환이 누락될 수 있음. 현재 상태로 과거 구간을 채우지 않음.
- 전체 기간을 기본으로 표시하고 날짜 선택 시 시간 확대. 기존 조회 기간·수집 상태·진척 집계 유지.
