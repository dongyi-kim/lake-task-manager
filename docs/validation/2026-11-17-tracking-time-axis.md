# Tracking 통합 시간축 검증

대상: `feat/tracking-time-axis`, 승인된 `tracking-time-axis.html` 시안의 실제 제품 적용.

## 검증 범위

- Task/Epic/Sub-task 선택 시 통합 축 한 개. 직속 하위 작업별 축은 선택적 확장.
- KST 실제 시각 배치, 전체 기간/09–18시/24시간, 야간·자정 경계.
- 상태 표식 16px, 댓글 18px, 한 줄 안내 24px. 같은 시각 상태 변경 12건의 x좌표 유지·y 분리·연결선 좌표.
- 438px 상세 패널 및 1440/1280 밝은·어두운 테마. 긴 중복 제목·티켓 키·가로 넘침.
- 같은 출처 댓글 74건 묶음과 다른 출처 2건 분리. 마지막 원본 접근·Esc·포커스 복귀.
- 원본 근거 이동, 기존 댓글 HTML/folding, VOC 투영 범위, 종단/비종단 및 스크롤 보존.
- 범위 선택·확대·댓글·하위 펼치기 중 추가 API 조회 없음.

## 결과

- 변경 전 단일 통합 축 회귀 검사: 날짜열 구현에서 예상 실패 확인.
- 1차 관련 회귀: 418 통과 / 5 실패. 집계 비교의 innerText/textContent 차이 4건과 펼치기 버튼 접근성 이름 변경 1건. 테스트 비교와 버튼 이름 수정 후 재검증 대상.
- 실개발 저장 run: Task DL-10000, 자체 상태 2건·댓글 74건·하위 주요 변화 11건. 넓은 본문에서 축 높이 248px, 안내 9개·묶음을 포함한 표식 19개 확인.
- 최종 관련 회귀: **426 통과**. 모델 12건과 실제 Vue/CSS 브라우저·기존 댓글·범위·정적 자산 검사 포함.
- 마지막 reduced-motion 보정 후 1440/1280 밝은·어두운 테마의 통합 축 4건 재검증 통과. 위 회귀의 부분집합이며 합산하지 않음.
- Tailscale 실제 화면: DL-101 Epic, DL-10000 Task, 기존 DL-5008 Story의 제목 아래 통합 축 확인. Task의 직속 하위 2개 확장/접기 및 시간 확대 확인.
- 실제 상세 패널 폭 397px에서 표시. 본문/상세·밝은/어두운 테마 확인. 추가 Tracking API 요청 0건, 브라우저 오류 0건, 페이지 가로 넘침 없음.
- 본문 공통 버튼 초기화가 말풍선 테두리·표식 색을 덮는 문제 수정. 본문 안내 1px 테두리·흰 배경·24px 높이 및 짧은 변화 문구의 생략 없음 확인.
- 독립 코드 검토 완료. 하위 사건만 있을 때 자체 기록 안내, KST 눈금, 양방향 안내 배치, CSS 격리, reduced-motion 보정 반영.

## 설계 적용 판정

- 일반 사건은 원본 근거로 바로 이동. 댓글 묶음만 같은 티켓의 전체 원본 목록 제공.
- 하위 축의 과거 상태 구간은 중립 점선. 저장 사건이 사람/기간 조건으로 투영되어 있으므로 전체 수집 완료 표식만으로 연속 상태를 보증하지 않음. 현재 상태를 과거 상태로 역추정하지 않음.
- 현재 조회된 직속 하위 완료 수/전체 수 유지. 부분 수집·미확인 상태는 비율 미확정.

모든 테스트 임시 산출물은 OS 임시 디렉터리에 생성하고 프로세스 종료 후 정리. 전체 저장소 suite·실 Jira 호출·배포는 이 검증에 포함하지 않음.
